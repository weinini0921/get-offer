# Get Offer

这是一个零成本、本地运行的网站原型。推荐流程已改为：

1. 在首页填写想投递的岗位和搜索关键词。
2. 可选粘贴或上传 PDF/txt/md 简历，用于推荐排序加权。
3. 进入“今日”页搜索公司名或填写公司招聘专站、校招站或 ATS 链接。
4. 搜索完成后，岗位结果直接展示在“今日”页中间列表。
5. 招聘源池支持勾选启用、移除默认源、删除自定义源和恢复默认源。

## 当前包含

- 按目标岗位和关键词做每日推荐
- 药企、快消、外企、美妆、互联网公司招聘专站源
- 第二页公司搜索：输入公司名自动定位招聘专站，填写招聘页则优先抓取
- 招聘源池增删管理：添加自定义公司、移除招聘源、清理自定义、恢复默认
- 本地招聘源抓取 API，不使用付费职位数据源
- 支持 txt、md、PDF 简历上传；PDF 由本地服务解析
- 免费 AI 简历分析：优先连接本机 Ollama 的 DeepSeek 系模型，失败则回退本地规则
- 简历/JD 本地规则匹配，不调用付费 AI API
- 求职轨迹看板
- 邮箱搜索入口与邮件正文粘贴解析
- 测评页支持点击笔试题型展开练习，并上传 JSON/CSV/TXT/MD 题库
- 浏览器本地存储，不需要数据库

## 本地打开方式

需要 Node.js 18 或更高版本。进入项目目录后运行：

```text
npm start
```

然后访问：

```text
http://127.0.0.1:4174/
```

如果需要解析 PDF 简历，请先安装免费的 Python 依赖：

```text
pip install -r requirements.txt
```

## 零成本边界

- 不使用付费 AI API。
- 默认 AI 地址是本机 `http://127.0.0.1:11434/api/generate`，模型名默认 `deepseek-r1:7b`。
- 如本机没有安装 Ollama 或 DeepSeek 系模型，网站仍可使用本地规则分析。
- 不使用付费邮件发送服务。
- 不使用付费职位数据库。
- 不绕过登录、验证码或招聘站反爬限制。
- 邮箱自动读取需要安全授权，当前免费原型用“打开邮箱搜索 + 粘贴邮件正文解析”实现轨迹同步。
